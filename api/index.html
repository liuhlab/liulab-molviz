Python API¶

This page lists the molviz package's names, each as its docstring describes it. Import each one from molviz, as in molviz.draw. A page that draws in the browser calls the viewer itself, through the names on the JavaScript API page.

Each input's keys are on its format's page: record, gel, plate and figure. Export SVG, PNG and PDF uses Drawing.write, and Put drawings in your own page uses still_svg, font_rules and viewer_script.

class Drawing:
    """An input drawn, as each of molviz's draw calls returns it. A caller never makes one.

    It lays out its file drawing the first time a ``.svg``, ``.png`` or ``.pdf`` file,
    ``hidden`` or ``notice`` needs it, and only once.
    """

    def __init__(
        self,
        name: str,
        data: dict[str, Any] | list[dict[str, Any]],
        title: str,
        options: dict[str, Any] | None = None,
    ) -> None:
        # `data` is the input called `name`, already checked. A page titled `title` hands that
        # input's draw call `data`, then any `options`.
        self._name = name
        # Each argument of the draw call by its block's id on a page. As text, so a change the
        # caller makes to an input afterwards never reaches the page or a file.
        given = {name: data} if options is None else {name: data, "options": options}
        self._arguments = {block: _json(value) for block, value in given.items()}
        self._title = title

    @property
    def hidden(self) -> list[dict[str, Any]]:
        """The labels left out because they would overlap.

        They are of what a file draws at full size, or of what a page opens on. Each is the
        viewer's ``Hidden``, defined in its ``labels.ts``: its ``kind``, ``name``, and ``spans``
        or, for a cut site, an insertion or a disagreement at a point, its point ``at``.
        """
        return self._drawn["hidden"]

    @property
    def notice(self) -> str:
        """The sentence that counts the hidden labels by kind, worded by the viewer.

        Such as "3 cut sites and 1 primer are hidden". Empty when nothing hides.
        """
        return self._drawn["notice"]

    @cached_property
    def _drawn(self) -> _FileDrawing:
        """The viewer's file drawing, laid out on first read."""
        return _runtime.call_json(self._name, "svg", self._arguments_json())

    def _arguments_json(self) -> str:
        """Return the draw call's arguments, as one JSON array."""
        return f"[{','.join(self._arguments.values())}]"

    def write(self, path: str | PathLike[str], dpi: float = 300) -> None:
        """Write the drawing to ``path``, in the format its ending names, in any case.

        The endings are ``.html``, a page that opens offline; ``.svg``; ``.png``, at ``dpi``
        pixels per inch; and ``.pdf``. One unit of the drawing is one point, so a PDF page is
        the drawing's own size and a PNG is that size in print, cut to whole pixels. A PDF of a
        record with its sequence view has the map on the first page and the rows on the pages
        after. A record's page draws it with the viewer; any other page holds its still SVG and
        no viewer.

        Raises
        ------
        ValueError
            If the ending is none of those, or if a PNG at ``dpi`` would pass 2**22 pixels on a
            side or 2**28 in all.
        """
        path = Path(path)
        match path.suffix.lower():
            case ".html":
                if self._name in _LIVE:
                    page = _page(self._title, self._name, self._arguments)
                else:
                    page = _still_page(self._title, self.still_svg())
                path.write_bytes(page.encode())
            case ".svg":
                path.write_bytes(self._drawn["svg"].encode())
            case ".png":
                most = _most_dpi(self._drawn["svg"])
                if dpi > most:
                    raise ValueError(
                        f"cannot write {path!s}: a PNG of this drawing is drawn at up to "
                        f"{math.floor(most):,} dpi, not {dpi:g}; write a PDF, which draws at any size"
                    )
                import vl_convert

                # vl-convert ships no type stub, so pyright cannot see its functions.
                png = vl_convert.svg_to_png(self._drawn["svg"], ppi=dpi)  # pyright: ignore[reportAttributeAccessIssue]
                path.write_bytes(png)
            case ".pdf":
                path.write_bytes(_pdf(self._drawn["pages"]))
            case _:
                raise ValueError(
                    f"cannot write {path!s}: its ending must be .html, .svg, .png or .pdf"
                )

    def still_svg(self) -> str:
        """Return the drawing as SVG with real text, for a page that holds no viewer.

        It is laid out as the ``.svg`` file is and hides the same labels. Each text is held to
        its measured width, and each hover is a ``<title>``. It draws in the viewer's faces
        only on a page that writes ``font_rules()`` once, in a ``<style>`` element.
        """
        return _runtime.call_json(self._name, "still", self._arguments_json())["svg"]

Options¶

draw takes these options by name, and so does draw_figure, for every record it stacks. Each says what the drawing starts with. An option it does not know is an error, and one left out takes its default. span counts bases as the record format's coordinates do. Choose what a map shows and Show the bases use each option in turn.

Option What it does Default
span Draws only the bases from start to end, as in {"start": 10, "end": 500}. start counts from 0, and the base at end is not drawn. The line is numbered as the record is. On a circular record, end may pass the record's length to run across the origin. the whole record
map The map to draw: "circle" or "line". The circle draws a circular record whole, so a linear record, or a span short of the whole record, must be drawn as "line". "circle" for a circular record drawn whole, else "line"
types_off The feature types to leave out. A type the record does not have is ignored. ["source"]
kinds_off The kinds of thing to leave out: any of "features", "primers", "cuts", "insertions", "reads", "disagreements" and "tracks". []
enzymes The enzymes whose cut sites are drawn. A name matches in any case. A name that does not cut the record is ignored. each enzyme that cuts the record once
highlight The names to light up: a feature, a primer, an insertion, a read, a disagreement, a track, or an enzyme, which lights every site it cuts. All else turns one pale grey, and nothing moves. Where labels crowd, a lit label is the last to hide. A name in any case matches. A name that matches nothing in the record is an error. []
sequence_view Draws the sequence view: the bases in rows, on both strands, with each thing drawn on them at its bases. On a page it sits beside the map, or under it when the room is narrow. In a file it sits under the map, and a PDF has the map on its first page and the rows on the pages after. It draws at most SEQUENCE_VIEW_LIMIT bases, 100,000, so past that true is an error. false
bases_per_row How many bases a row of the sequence view holds. The last row may hold fewer. Left out, a page fits its rows to the width it has, from 20 to 100 bases in steps of 10. A row too wide for the page keeps its length, and the sequence view is drawn smaller to fit. fits the width on a page, 60 in a file
bottom_strand Whether the sequence view draws the bottom strand under the top one. true

The command line¶
